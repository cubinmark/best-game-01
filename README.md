The entry for make.fun's “Make the best game” bounty. NEON HARVEST is an original 2D canvas arcade game in vanilla JavaScript with no libraries and no network calls: pilot a harvester drone over a synthwave grid, chain glowing orb pickups into a x8 combo multiplier, dodge patrolling sentinel drones, and clear three timed waves with rising score targets. `main.ts` copies `game/` and `screenshots/` to the output directory and writes `dossier.json` with the kit's vendored `buildDossier`.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=out node main.ts   # then serve game/ with any static server and open index.html
```
